\section{Summary}
The objective was to identify Berlin property managers that may need a modern metering and energy-operations provider. The final workbook contains 266 private leads plus 25 Strategic accounts, from 2,709 raw rows after 1,588 duplicate merges. Leads are split into Tier A/B/C: 12/90/164. It includes 157 named contacts, 34 LinkedIn matches, and 33 private leads with known units.

\section{Approach and workflow}
\begin{enumerate}
\item Discover companies through Google organic and Places search plus Berlin directories.
\item Clean names and encoding, normalize domains, verify Berlin postcodes, and deduplicate.
\item Check each website and separate live company sites from Directory-only rows.
\item Crawl company pages including Impressum, contact, services, team, portal, and careers pages.
\item Extract KPI values only when supported by verbatim evidence from the company's own pages.
\item Score fit using the configured weighted rules and assign Tier A, B, C, or Strategic.
\item Find decision makers, business emails, and search-result LinkedIn matches.
\item Run deterministic quality gates, export CSV/XLSX, and retain source provenance.
\end{enumerate}

\section{Contacts}
Decision makers were selected from Impressum and team pages, supported by search and Hunter. Email labels distinguish \texttt{hunter\_verified} (7), \texttt{hunter\_accept\_all} (1), and \texttt{mx\_ok\_unverified} (29); guessed addresses remain in a separate field. LinkedIn was not scraped directly: 34 matches used search-result evidence with surname and company anchors. The workbook contains 157 named contacts.

\section{Data validation}
The pipeline checks live company websites, rejects directory and redirect URLs as company websites, requires a Berlin postcode, removes duplicate domains and names, requires evidence quotes for KPI values, checks KPI source domains against the company domain, separates role mailboxes from personal contacts, and applies MX/Hunter checks. A dedicated audit stage and unit tests verify these rules. The final hard audit passed all implemented quality gates.

\section{Automations and limitations}
Stages can be run from one command, HTTP and model responses are cached for resumability, and LLM calls are logged. The workbook has 266 Leads, 25 Strategic, 99 Directory-only, 731 Excluded, and 7 Sources rows plus a README and Validation tab. Units are known for 33 private leads; many email records are domain-checked rather than individually verified. Some candidates remain excluded because a provable Berlin postcode was unavailable. LinkedIn evidence is search-only. The project uses public business information for B2B legitimate-interest outreach. Code was built with a GitHub Copilot harness; the agents use an LLM.
